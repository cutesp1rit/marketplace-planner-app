# Marketplace Planner

Веб-приложение для планирования и оптимизации поставок на маркетплейсы на основе прогноза спроса. Первый рассматриваемый сценарий - Ozon.

## Структура

- `backend/` - серверная часть, работа с данными и оптимизация поставок.
- `frontend/` - пользовательский интерфейс.

Серверная и клиентская части находятся в одном репозитории. Они могут иметь отдельные зависимости, сборку и развертывание.

## Состояние

Подготовлена структура проекта. Стек, интерфейс обмена с подсистемой прогнозирования и команды запуска еще не определены. Реализация приложения не начата.

Реальные данные магазина и ключи доступа не входят в репозиторий. Инструкция запуска и демонстрационные данные будут добавлены вместе с реализацией.
